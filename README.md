# Joel.Noir

Portfolio of Joel.Noir, creative designer and art director.
Cinematic, editorial visuals for sport, fight, events, branding and web.

## Stack

Next.js · React · TypeScript · Tailwind CSS · GSAP · Lenis · Motion

## Local development

    npm install
    npm run dev

The site runs at http://localhost:3000.

## Production build

    npm run build
    npm start

## Structure

- `src/app`: routes (home, project detail, legal pages, sitemap, robots)
- `src/components`: sections, layout and UI
- `src/lib`: content (DE/EN), project data and case studies
- `public/work`: project imagery
